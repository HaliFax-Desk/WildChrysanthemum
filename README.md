# Wild Chrysanthemum Dataset

## Overview

本数据集包含野菊花丛的照片和视频，以及从中提取的包含蜜蜂行为的图像帧。所有数据均为原始未标注数据，可用于计算机视觉、图像识别、蜜蜂行为研究等领域。

## Directory Structure

```
WildChrysanthemum/
├── raw/                    # 原始照片
│   ├── *.jpeg             # 相机拍摄的野菊花丛照片 (287张)
│   └── *.jpg              # 视频截帧照片 (4张)
├── raw_media/             # 原始视频
│   ├── *.MOV              # HDR视频文件 (4个)
│   ├── *.mp4              # HDR视频文件 (3个)
│   └── README.md          # 视频说明
└── Select/                # 精选视频截帧
    ├── BeesInField/       # 蜜蜂在野菊花丛中的逐帧图像
    ├── BeesOnField2/      # 蜜蜂在野菊花丛中的逐帧图像 (第二部分)
    └── README.txt         # 图像说明
```

## Data Specifications

### 照片 (raw/)

- **格式**: JPEG (.jpeg) 和 JPG (.jpg)
- **分辨率**: 4000×3000 像素以上
- **DPI**: 水平和垂直分辨率均 ≥ 72 DPI
- **位深**: 24 位
- **焦距**: 等效全画幅约为 23 毫米和 70 毫米
- **内容**: 
  - .jpeg 文件：相机直接拍摄的野菊花丛照片
  - .jpg 文件：从视频中截取的帧

### 视频 (raw_media/)

- **格式**: MOV 和 MP4
- **特性**: HDR 格式
- **焦距**: 等效全画幅约为 23 毫米和 70 毫米
- **内容**: 包含蜜蜂在野菊花丛中穿过或访花行为的视频

### 精选图像 (Select/)

- **内容**: 从视频中提取的精选帧
- **特点**: 每一帧都包含蜜蜂在野菊花丛中飞舞、访花的行为，均为连续帧
- **状态**: 原始数据，未经过标注或修改
